## 1. 数据模型

八张表。一期落地前六张（§1.1–§1.6），`factors` 与 `macro_scenarios` 在三、四期启用，但**字段在一期建表时预留**，避免后期迁移。

#### 1.4.1 thresholds 结构

```json
[{
  "id": "th_risk_vix",
  "name": "短线风控线",
  "series_id": "MACRO.VIX",
  "operator": ">",
  "value": 19,
  "type": "风控线",
  "horizon": "短期",
  "action_hint": "降敞口"
}]
```

`type` 枚举：风控线 / 介入位 / 观察位
`action_hint` 为文字提示，平台不执行任何动作

#### 1.4.2 falsifiers 结构

```json
[{
  "id": "fl_myanmar",
  "desc": "缅甸月进口回到万吨",
  "series_id": "CUSTOMS.2609.import.MM",
  "expression": "value >= 10000",
  "unit_confirmed": "实物吨",
  "consecutive_periods": 1,
  "side": "bull"
}]
```

`side` 表示该条证伪打击的是主逻辑的哪一边（bull / bear）
`consecutive_periods` 支持"连续 N 期"类条件
**约束**：`series_id` 必填且必须存在于 indicators；`unit_confirmed` 必填

### 1.10 series_id 命名规则

`{来源}.{品种}.{对象}.{细分}`，全大写，点分隔。

| 示例 | 含义 |
|---|---|
| `SHFE.SN.2610.settle` | 上期所锡 2610 合约结算价 |
| `SHFE.SN.0.last` | 沪锡主力连续最新价 |
| `SHFE.SN.stock.daily` | 上期所锡库存日报 |
| `SMM.SN.spot.1` | SMM 1# 锡现货均价 |
| `CUSTOMS.2609.import.MM` | 海关锡矿砂进口，缅甸 |
| `CUSTOMS.2609.import.total` | 海关锡矿砂进口总量 |
| `MYSTEEL.SN.TC.YN40` | Mysteel 云南 40% 锡精矿加工费 |
| `MACRO.VIX` | VIX |
| `FX.USDCNY.mid` | 人民币中间价 |

### 1.11 formula_id 清单（一期）

| formula_id | 公式 | 时点容差 |
|---|---|---|
| `BASIS` | 现货价 − 指定合约价 | 同交易日且 ≤ 4 小时 |
| `BASIS_RATE` | BASIS ÷ 合约价 | 同上 |
| `SPREAD_M1M2` | 近月 − 次月 | 同交易日、同价格类型 |
| `SPREAD_ANNUAL` | 价差 ÷ 近端价 ÷ 跨月数 × 12 | 同上 |
| `SPREAD_VS_CARRY` | 价差 ÷ 估算持有成本 | 同上 |
| `STOCK_CHG_D` | 当日库存 − 前一交易日库存 | 相邻交易日 |
| `IMPORT_YOY` | 当月量 ÷ 去年同月 − 1 | 同 HS 码同口径 |
| `IMPLIED_PRICE` | 金额 ÷ 数量 | 同月同 HS 码 |

## 3. 口径字典（一期必须定稿）

| 口径维度 | 枚举值 | 说明 |
|---|---|---|
| 重量口径 | 实物吨 / 金属吨 | 锡精矿进口两者相差 2–3 倍，必须标明。证伪条件"回万吨"按实物吨判定 |
| 价格类型 | 最新价 / 结算价 / 收盘价 / 均价 | 跨期价差两端必须同类型；成交清淡合约默认用结算价 |
| 合约标识 | 主力连续（SN0）/ 具体合约（SN2610） | **两者不可混算**。主力连续在换月时会跳价 |
| TC 品位 | 40 度 / 60 度 | 不同品位数值不可比 |
| 库存范围 | 交易所库存 / 社会库存 / 保税库存 / 隐形库存 | 隐形库存无公开数据，只能来自调研 |
| 现货来源 | SMM / 长江有色 | 两家报价口径不同，页面可并列展示但不可混算 |
| 进口口径 | 精矿（HS2609）/ 精锡（HS8001）/ 废碎料 | 不可合并计算 |
| 时点类型 | 交易时点 / 发布时点 / 抓取时点 | `as_of` 存交易或数据代表时点，不存抓取时点 |

## 4. 判断模板字段规格

### 4.1 主逻辑 contradiction

```json
{
  "bull": { "claim": "矿端供应紧",
            "evidence": [{"desc":"...","series_id":"...","value":...,"as_of":"..."}] },
  "bear": { "claim": "下游需求弱",
            "evidence": [...] },
  "window": { "from": "2026-09", "to": "2026-10", "note": "开工率与库存方向是关键验证期" }
}
```
**校验**：bull 与 bear 均非空，各至少一条证据。

### 4.2 短线边际 marginal_focus
数组，每条含描述与关联 series_id。校验：至少一条。

### 4.3 成本线 cost_line
必须选择 `cash`（现金成本）或 `full`（完全成本）；填写数值时必须给来源。提示语："趋势空品种以现金成本为准，且需考虑成本曲线下移。"

### 4.4 边际定价权 pricing_power
短期与中长期分开。候选项按外盘类型给出：有 LME 外盘 / 纯宏观 / 无外盘。
**校验（审稿清单）**：此处声明的来源应在白名单中有对应指标，否则告警。

### 4.5 时间维度 time_dimension
短期与中长期分开填写。提示语："长期叙事不能用来解释短期价格。"

### 4.6 调研信息差 survey_notes
一期自由文本，提示填写四要素：立场、样本、时点、价格是否已反映。二期结构化。

### 4.7 指标白名单 whitelist
3–8 个，下拉选择。要求覆盖供需双侧 + 利润或价差，来源多元。

### 4.8 编排范式 paradigm
总线合成 / 对抗称重 / 编排层，三选一，影响 agent 侧调用方式。

### 4.9 基调 tone（固定词表）
偏多 / 偏空 / 观望 / 区间震荡 / 回调买入 / 反弹偏空 / 等信号

## 5. UI 规范

### 5.1 色板

| 用途 | 说明 |
|---|---|
| 主色 | 深蓝，用于标题、链接、图表主序列 |
| 强调色 | 暖褐，用于强调与选中态，不用于表达涨跌 |
| 警示 | 暗红，仅用于证伪触发、判断过期、计算被拦截 |
| 中性灰 | 次要文字、口径注释、时间戳 |
| 涨跌 | 遵循国内习惯（红涨绿跌），且**只用于价格涨跌，不用于表达多空判断** |

支持浅色与深色两套，跟随系统。

### 5.2 字号与密度

| 层级 | 用途 |
|---|---|
| 大号 | 核心数字（六个核心数、基调） |
| 正文 | 说明文字，行高宽松 |
| 小号 | 口径、时点、来源标注，中性灰 |

数字统一使用等宽数字（tabular-nums），便于纵向比较。

### 5.3 数据可信度的视觉表达

| 状态 | 表达 |
|---|---|
| 自动取数、正常 | 常规样式 |
| 人工录入 | 数值后加小标记 `人工`，hover 显示录入人与时间 |
| 代理指标 | 名称后加 `代理` 标记 |
| 延迟 | 时间戳标为橙色 |
| 缺失 | 显示"暂无数据"+ 预期更新时间，**不显示 0，不沿用上一日值** |
| 被拦截的派生值 | 显示"口径不一致，暂不计算"+ 冲突说明 |

### 5.4 组件清单（一期）

| 组件 | 用途 |
|---|---|
| 判断状态条 | 基调 + 版本 + 过期标记 + 待办入口 |
| 信号条目 | 条件 + 当前值 + 阈值 + 状态 + 证据链接 |
| 核心数字卡 | 数值 + 单位 + 时点 + 来源 + 可展开的口径说明 |
| 数据表 | 排序、CSV 导出、价格类型列 |
| 期限结构图 | 折线，区分活跃与清淡合约 |
| 时间序列图 | 单序列为主，不用双轴 |
| 分布条形 | 分国别占比，含集中度与 HHI |
| 表单段 | 独立保存 + 校验提示 + 草稿留存 |
| 差异视图 | 判断版本 diff |
| 空态卡 | 引导操作 |

### 5.5 图表通用规则

1. 每张图右下角标注数据时点与来源
2. 不使用双轴
3. 颜色只区分序列，不表达多空
4. 派生值图表必须可展开查看输入与时点
5. 口径变更处断开序列并注明，不做平滑连接

## 7. 术语表

| 术语 | 含义 |
|---|---|
| 判断单元 | 一个品种的结构化研究判断，含九字段、阈值、证伪、优先级 |
| 口径 caliber | 一个数字的度量前提：合约、品位、重量单位、价格类型、统计范围 |
| 数据时点 as_of | 这个数代表哪一刻，区别于抓取时点 |
| 同时点校验 | 派生计算前检查各输入时点是否在容差内 |
| 证伪条件 | 事先写好的"出现什么情况说明判断错了"，必须绑定可取数指标 |
| 冲突优先级 | 多条阈值同时触发且指向相反动作时的裁决顺序 |
| 共享驱动因子 | 同时影响多个品种的要素 |
| regime | 市场所处状态（如加息周期），决定各维度权重 |
