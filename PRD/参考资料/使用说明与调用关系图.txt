## 一、体系是什么

一套「有自主研究意识的agent」: 给定任意品种/问题, 按统一法则自主完成
取数→分项分析→合成裁决→编排产出→决策 全流程。三层结构:
- **通用法则层**(00_通用法则): 研究方法 + 编排契约, 所有品种共享
- **板块层**(01-06): 板块共享法则(有色强弱/黑色链条/能化成本定价等)
- **品种层**: 77个品种研究逻辑, 每品种按统一目录树模板

## 二、怎么用(按场景)

### 场景1: 研究一个品种(最常用)
```
1. 定位: 查 01-06板块/{品种}_研究逻辑.txt
   - 已有该品种逻辑 → 直接读, 套用主逻辑/边际/指标/基调
   - 无 → 从 00_通用法则/总纲 第二部分派生(填写目录树模板)
2. 取数: 按研究逻辑的"指标白名单"批量取数(知几API)
3. 分析: 主逻辑(方向) + 短线边际(执行) + 成本线(底部锚)
4. 输出: 基调 + 关键指标 + 调研信息差(含证伪)
```

### 场景2: 写渊行矛盾文案
```
1. 读 00_通用法则/总纲 第二部分(通用研究法则)
2. 按品种研究逻辑的主逻辑/边际/基调 → 填入 build_fundamentals.py
   的 CONTRADICTIONS/SURVEY_NOTES
3. 格式: 矛盾三段式(大矛盾+边际+基调) + 调研纪要(≤100字带日期来源)
```

### 场景3: 做晨报/周报(多agent编排)
```
1. 确定编排范式(三选一):
   - 单品种多驱动 → 总线合成(黄金A-F式): 用 合成层 模板
   - 多空争议大 → 对抗称重(工业硅式): 多头/空头逻辑 → 观点合成
   - 维度多 → 编排层(铝晨报式): 分项agent → 晨报汇总
2. 数据层: 各分项agent用【标准化摘要】接口协议输出
3. 合成层: 用 合成层_观点称重与裁决.txt 称重
4. 编排层: 用 编排层_晨报周报汇总.txt 去重+去Agent化写作
```

## 四、硬约束速查(所有agent共享)

1. 防重复取数: 多空/分项共用同一图表清单
2. 防编造: 数字必须有来源, 禁心算臆造
3. 防超时: 取数显式limit, 分批(图表≤50/指标≤50/语料≤5每批)
4. 观点稳定性: 短期不跨零直翻, 反转需主导矛盾切换/硬数据证伪/关键结构突破
5. 输出: ETA Froala富文本只认HTML; 晨报去Agent化
6. 调研信息差: 带立场/样本/时点三重标注 + 证伪条件, 不奉为圭臬
