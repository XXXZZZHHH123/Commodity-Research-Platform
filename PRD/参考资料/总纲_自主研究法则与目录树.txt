# 目录: 自主研究agent体系/00_通用法则(本目录) → 01_有色/02_黑色/03_能化/04_农产品/05_贵金属/06_金融与宏观

## 一、体系定位

本体系是「有自主研究意识的agent」: 给定任意品种/问题, 按统一法则自主完成
取数→分项分析→合成裁决→编排产出→决策 全流程。核心是两层:
- **通用法则层**(本文件): 不变的研究方法与编排契约, 所有品种共享
- **品种/板块子目录**: 只放差异化——每品种的主逻辑、边际定价权、指标白名单、编排范式

## 二、通用研究法则(方法层, 每品种必过一遍)

### 1. 不变主逻辑 + 灵活短线边际(核心结构)
- **不变主逻辑**(contradiction): 每品种一个结构性矛盾, 不随日度数据变
  - 双向对立(供给驱动vs需求现实) + 数据锚(数字/日期/阈值) + 验证窗口
  - 例: 锡"矿紧(TC17,500)vs需求弱(单耗下滑), 40万补货线夹击, Q4验证"
- **灵活短线边际**(marginal_focus): 日度/周度数据驱动, 随库存/排产/成本/基差/外盘变
  - 竖线分隔短线催化, 数据变就重估
  - ⛔ 边际只调执行、不推翻主逻辑方向

### 2. 成本线原则(趋势空品种命门)
- 用**现金成本**(生产决策线), 非完全成本(账面口径)
- **成本会下移**: 技术进步持续拉低成本曲线, 拿静态成本当锚是错
- 价格接近现金成本→边际产能减产→空单收敛; 跌破→减产启动见底信号
- 例: 多晶硅真实成本=头部现金成本2.3-3.3万(非市场以为的4-5万完全成本)

### 3. 短期边际定价权判定(不是一刀切)
- **有LME外盘**≠短期都在海外: 锌→伦锌挤仓 | 铝→伦铝地缘+海外复产 | 铜→宏观+COMEX
  锡→宏观(SOX)+矿端事件 | 镍→印尼供给 | 铅→国内再生铅(LME边缘化)
- **金银=纯宏观**(美债/美元/实际利率), 不掺国内/工业
- **无外盘**(氧化铝/工业硅/多晶硅/锂/鸡蛋/花生)= 短期看国内供需+政策+宏观情绪

### 4. 时间维度分配
- 短期: 当期边际(地缘/挤仓/事件)——随数据调整
- 中长期: 结构性(海外复产/矿紧/过剩/产能释放)——不变主逻辑
- ⛔ 别把中长期故事塞进短期(铝的海外复产是中长期, 短期只是地缘溢价退潮)

### 5. 调研信息差融入(最增值, 见 我的/调研纪要信息差辩证法提示词)
- 调研纪要是"假设发生器+跟踪雷达", 非结论——带立场/样本/时点三重标注
- 价格锚(下游真实补货意愿价) | 产能≠产量(政策/配额/电力函数) | 量价背离(拆量×价)
- 时点分布(增量落哪个季度) | 共享要素联动(找跨品种共享生产要素)
- 引用调研结论必过四问: 立场?样本?时点?价格是否已反映?

## 三、分层编排契约(架构层, 融合三范式)

从库内三套成熟范式提炼: 黄金总线合成(Agent黄金A-F) + 工业硅对抗称重(多空+观点)
+ 铝编排层(分项agent→晨报/决策). 统一为五层:

```
┌─ ① 数据层: 指标白名单 + 批量取数 ─────────────────────────────┐
│    - 每品种专属 chart/指标 ID 白名单(禁清单外)                 │
│    - 批量取数: 图表≤50/指标≤50/语料编码≤5每批, 显式limit       │
│    - 失败重试1次后跳过不中断; 防超时                           │
├─ ② 分项分析层: 单维度诊断 ───────────────────────────────────┤
│    - 多头/空头对抗(共用同一图表清单, 强制"同一事实基础")       │
│    - 分维度: 宏观/利率/供需/库存/成本/跨品种, 各自输出结构化标签│
│    - 【标准化摘要】字段协议(给下游稳定读取):                  │
│      Agent名/核心信号/影响方向/可信度0-100/核心结论/关键证据/  │
│      主要冲突/数据缺口/后续验证                               │
├─ ③ 合成裁决层: 称重/加权 ────────────────────────────────────┤
│    - 读分项语料(latest_corpus_by_schedule_code + 精确T-code)  │
│    - 黄金式: regime动态权重 + 趋势开关 + 证伪校验              │
│    - 工业硅式: 逐维度对冲 + 主导矛盾 + 拥挤度 + 分时间维度方向 │
│    - 观点稳定性: 短期不跨零直翻, 中期达反转门槛才翻面          │
├─ ④ 编排产出层: 晨报/周报 ────────────────────────────────────┤
│    - 跨agent去重 + 降级预案 + 去Agent化写作(不出现agent/上游)  │
│    - 数据真实性: 数字必须有来源, 禁心算臆造                   │
├─ ⑤ 决策层(可选): 交易策略 + 台账 ────────────────────────────┤
│    - 读合成结果+技术面+台账持仓快照, 出当日动作表              │
│    - 点位纪律/仓位规则/每手风险折算                           │
└──────────────────────────────────────────────────────────────┘
```

### 编排范式三选一(按品种特性选)
| 品种特性 | 范式 | 代表 |
|---|---|---|
| 单品种多驱动(利率/宏观/供需/技术) | 黄金E式总线合成(一个总指挥读所有分项) | 黄金A-F |
| 多空争议大、需正反论证 | 工业硅式对抗+称重(多头/空头→观点合成) | 工业硅/多晶硅 |
| 维度多且各司其职 | 铝式编排层晨报+决策层分离(分项→晨报/决策) | 铝网络 |

## 四、目录树模板(每个品种研究逻辑的标准骨架)

```
【板块】XX
├─ 主逻辑 contradiction(双向矛盾+数据锚+验证窗口)
├─ 短线边际 marginal_focus(竖线分隔, 数据变就重估)
├─ 成本线(现金成本+考虑下移, 现价在哪侧)
├─ 边际定价权(有LME/纯宏观/无外盘→看谁)
├─ 时间维度(短期边际 vs 中长期结构性)
├─ 调研信息差(价格锚/产能vs产量/量价背离/时点/共享要素)
├─ 指标白名单(3-5个, 覆盖供需双侧+利润价差, 来源多元)
├─ 编排范式(总线/对抗/编排层 三选一)
└─ 基调(偏多/偏空/观望/区间震荡/回调买入/反弹偏空/等信号)
```

## 五、硬约束(所有agent共享, 禁违反)

1. 防重复取数: 多空/分项共用同一图表清单
2. 防编造: 数字必须有来源, 禁心算臆造, 季节性同比只做定性
3. 防超时: 取数显式limit, 分批, 失败重试1次跳过
4. 观点稳定性: 短期不跨零直翻, 反转需主导矛盾切换/硬数据证伪/关键结构突破
5. 输出格式: ETA Froala富文本只认HTML; 分项用记录块【记录N】; 晨报去Agent化
6. 数据新鲜度: 区分"正常滞后"vs"真失效", 核心数据滞后>2交易日才拦截
7. 证伪校验: 价格破证伪位旧方向作废
