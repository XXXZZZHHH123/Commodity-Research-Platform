# 一期 PRD · 看板与报告

> 版本 v1.0 ｜ 2026-09-18 ｜ 上级文档 `00_总控.md` ｜ 字段与规范见 `04_附录_数据字典与设计规范.md`
> 一期品种：**锡（SN）**，单品种跑通

---

## 1. 目标与范围

### 1.1 一期目标

把锡的研究判断从一份静态文档，变成系统里一个**可录入、可自动比对、可每日查看**的活对象。

三条具体目标：
1. 研究员不再手工抄一期覆盖的数据；
2. 锡的判断在系统中有结构化记录与版本；
3. 阈值与证伪条件每日自动比对，触发即提示。

### 1.2 范围内

- 判断录入表单（九字段 + 阈值 + 证伪 + 优先级）
- 指标登记表与口径字典
- 免费公开源自动取数
- 人工录入通道与数据缺口标记
- 派生计算与同时点校验
- 阈值与证伪监测、判断到期提醒
- 品种页、判断页、指标管理页、日报归档页
- 每日快照导出（HTML / JSON / CSV）
- 登录与操作留痕

### 1.3 明确不做（及理由）

| 不做 | 理由 |
|---|---|
| 通用模板工具、多研究员协作、审稿工作流 | 需第二位研究员试用后才知道怎么设计，放二期 |
| 新闻聚合与早班车 | 不进入判断闭环；现成框架二期接入成本很低 |
| 合成层、多分项称重 | 只有一个品种、一份判断时无物可合成 |
| 订阅接口（社库、TC、开工率） | 一期不依赖，用人工录入兜底，避免被外部排期卡死 |
| 告警推送到企微飞书 | 一期在页面内提示即可 |
| 管理层视图、命中率复盘 | 早期出现"给领导看的页面"会改变产品性质 |
| 交易建议、下单、实时行情 | 非研究场景需求 |

## 3. 功能需求

### FR-1 判断录入表单

**FR-1.1 九字段结构**
字段取自研究总纲的目录树模板，逐字段规格见 `04_附录 §4`：

| 字段 | 必填 | 校验 |
|---|---|---|
| 主逻辑 contradiction | 是 | 必须填多空两边，每边至少一条证据；缺一边不通过 |
| 短线边际 marginal_focus | 是 | 至少一条，每条关联一个已登记指标 |
| 成本线 | 否 | 填写时必须区分现金成本与完全成本，并注明数值来源 |
| 边际定价权 | 是 | 分短期与中长期，各选一项或多项来源 |
| 时间维度 | 否 | 短期与中长期分开填写 |
| 调研信息差 | 否 | 一期只做自由文本；结构化录入放二期 |
| 指标白名单 | 是 | 3–8 个，从指标登记表下拉选择，不可手工输入 |
| 编排范式 | 否 | 三选一：总线合成 / 对抗称重 / 编排层 |
| 基调 | 是 | 从固定词表选择：偏多 / 偏空 / 观望 / 区间震荡 / 回调买入 / 反弹偏空 / 等信号 |

**FR-1.2 阈值集**
每条阈值包含：名称、关联指标、方向（大于/小于/区间）、数值、类型（风控线/介入位/观察位）、生效时段（短期/中长期）。

**FR-1.3 冲突优先级（必填）**
当两条及以上阈值可能同时触发且指向相反动作时，必须指定优先级顺序。**表单在存在两条以上阈值时强制要求填写此项**，否则不允许提交。

> 设计依据：现有锡 prompt 在"价格到达介入位"与"宏观风控线亮起"同时发生时无优先级规则，导致执行层卡住。

**FR-1.4 证伪条件**
每条证伪条件包含：描述、**绑定指标（必填，从登记表选择）**、判定表达式、单位口径确认。绑不上指标的证伪条件不允许提交，提示"该证伪条件无法自动验证，请改写为可观测形式"。

**FR-1.5 版本与生命周期**
- 每次保存生成新版本，记录作者与时间，可查看任意两版 diff。
- 必填：写定日期、复核周期（默认 30 天）。
- 状态机：`生效` → `已到期`（超过复核周期）/ `已被证伪`（证伪条件触发并经作者确认）/ `已归档`（被新版本取代）。

**FR-1.6 审稿清单**
提交前自动检查，不通过项以警告呈现（不阻断提交，但记录）：

| 检查项 | 触发条件 |
|---|---|
| 指标只填了绝对值 | 阈值关联的指标为 TC、库存等存量型，但未填写方向或历史分位 |
| 单位口径未确认 | 数量型指标未选择口径（实物吨/金属吨等） |
| 结论引用了未登记的数值 | 文本中出现数字但无对应指标或来源标注 |
| 白名单与定价权脱节 | 定价权字段声明的来源（如宏观）在白名单中无对应指标 |
| 证伪条件方向可疑 | 证伪条件的判定方向与主逻辑同向（疑似写反） |

**FR-1.7 导入**
支持粘贴现有 prompt 文本，系统按段落标题预填对应字段，研究员确认后保存。不要求解析准确率，只求减少初次录入的打字量。

### FR-2 指标登记与口径字典

**FR-2.1 指标登记**
每个指标登记项含：`series_id`、名称、品种、口径、单位、来源、更新频率、是否一期覆盖、取数方式（自动/人工）、负责人。

**FR-2.2 口径字典**
维护口径枚举值及说明，供登记时选择。一期必须覆盖的口径见 `04_附录 §3`，其中至少包括：实物吨与金属吨、结算价与最新价与收盘价、TC 品位（40 度/60 度）、库存统计范围（交易所库存/社会库存/保税库存）。

**FR-2.3 约束**
判断表单中的白名单、阈值关联指标、证伪绑定指标，**只能从已登记的指标中选择**。

### FR-3 自动取数（一期范围）

| 数据 | 来源 | 频率 | 方式 |
|---|---|---|---|
| 沪锡全合约行情（最新价、结算价、涨跌、成交、持仓） | 上期所 | 每交易日收盘后 | AKShare / 官网文件 |
| SHFE 锡库存与仓单 | 上期所 | 日报与周报 | AKShare / 官网文件 |
| 锡矿砂进口 HS2609（总量、同比、隐含单价、分国别、集中度） | 海关在线查询平台 | 月度 | 适配器；降级为人工月度导出 |
| 未锻轧锡进口 HS8001 | 同上 | 月度 | 同上 |
| 人民币汇率中间价 | 外汇交易中心 | 每日 | 官网 |
| VIX | CBOE | 每日 | 官网免费数据 |

**FR-3.1 取数规则**
- 每次取数写入 `observations`，带 `caliber`、`as_of`、`fetched_at`、`source`、`source_url`。
- 失败重试 1 次，仍失败则标记 `status=缺失` 并在页面显示数据缺口，不中断其余取数。
- 同一 `series_id` + `as_of` 重复取数时，若值不同，写入新记录并递增 `revision`，保留历史。

**FR-3.2 不在一期自动取数的指标**
社库、锡精矿 TC、焊料开工率、ICDX 成交量、LME 价格与库存、SOX、加息概率——一期通过 FR-4 人工录入，并在页面标注来源为人工。

---

### FR-4 人工录入通道

**FR-4.1** 任何已登记指标均可人工录入数值，必填 `as_of` 与来源说明，系统自动记录录入人与录入时间，`source` 标记为"人工"。

**FR-4.2** 页面上人工录入的数值需有视觉区分（见 `04_附录 §5`），并显示录入时间。

**FR-4.3** 超过预期更新频率仍未录入的指标，在品种页"数据缺口"区列出。

---

### FR-5 派生计算与同时点校验

**FR-5.1 一期派生指标**

| 派生值 | 公式 | 输入时点容差 |
|---|---|---|
| 基差 | 现货价 − 指定期货合约价 | 同一交易日，且两端时点差 ≤ 4 小时 |
| 基差率 | 基差 ÷ 期货价 | 同上 |
| 跨期价差 | 近端合约 − 远端合约 | 同一交易日同一价格类型（同为结算价或同为最新价） |
| 价差年化 | 跨期价差 ÷ 近端价 ÷ 跨月数 × 12 | 同上 |
| 月差相对持有成本 | 跨期价差 ÷ 估算持有成本 | 持有成本参数可配置 |
| 库存日变化 | 当日库存 − 前一交易日库存 | 相邻交易日 |
| 进口同比 | 当月量 ÷ 去年同月量 − 1 | 同口径月度 |
| 隐含单价 | 金额 ÷ 数量 | 同月同 HS 码 |

**FR-5.2 校验规则（核心需求）**
- 每个派生值必须声明输入的 `series_id`、价格类型与时点容差。
- 不满足时不计算，状态置为 `blocked_timestamp_mismatch` 或 `blocked_caliber_mismatch`，页面显示"口径不一致，暂不计算"及原因，**不得输出一个看似正常的数值**。
- 每个派生值可展开查看：用了哪些输入、各自的 `as_of`、各自的来源。

**FR-5.3 流动性规则**
计算跨期价差时，若某合约当日成交量低于阈值（默认 500 手），默认改用结算价并在页面标注"成交清淡，采用结算价"。

---

### FR-6 阈值与证伪监测

**FR-6.1** 每日取数完成后，对当前生效判断的全部阈值与证伪条件执行比对，生成 `signals` 记录：触发状态（未触发 / 触发 / 数据缺失）、证据（指向具体观测或派生记录）、生成时间。

**FR-6.2** 触发时在品种页顶部显示，并在日报中列出。一期不做外部推送。

**FR-6.3 多期条件**
支持"连续 N 期"类条件（例："社会库存连续两周累库"），系统按指标的更新频率自动判定连续期数。

**FR-6.4 判断到期**
超过复核周期的判断，在品种页、判断页、日报与 JSON 快照中均标注"判断已过期 N 天"。到期后不停止监测，但所有输出带此标记。

**FR-6.5 证伪触发后的处理**
证伪条件触发时生成一条待确认事项，指派给判断作者，要求选择：维持 / 修正 / 作废。未处理事项在品种页常驻显示。

---

### FR-7 每日快照导出

**FR-7.1 HTML 日报**：每日收盘后生成，含判断状态、信号、核心数据、数据缺口。按日期归档，可回看历史。

**FR-7.2 JSON 快照**：结构见 `04_附录 §1.9`，供 agent 读取。一期即按标准化摘要协议对齐字段名。

**FR-7.3 CSV 导出**：品种页任一数据表可导出当前视图。

---

### FR-8 登录与留痕

**FR-8.1** 一期使用简单账号登录，不做权限分级（待决事项 #5 定后调整）。

**FR-8.2** 记录操作日志：判断的增改、人工数据录入、证伪确认动作。

## 4. 页面设计

### 4.1 信息架构

```
登录
└── 品种页（默认落地页，直接是锡的今天）      ← 主要页面
    ├── 判断页（查看 / 编辑 / 版本历史）
    ├── 指标管理页（登记表 / 口径字典 / 人工录入）
    └── 日报归档页（按日期列表）
```

导航为顶部一行四个入口，不做侧边栏、不做多级菜单。

### 4.2 品种页

**首屏只放三块**（原则 P4）：

**区块 A — 判断状态条**
- 基调（大字）、判断版本号、写定日期、`已过期 N 天` 标记（如有）
- 主逻辑一句话摘要（多方 vs 空方）
- 待确认事项入口（如有证伪触发）

**区块 B — 触发中的信号**
- 只列触发中与数据缺失的条目，未触发的折叠为一行"其余 N 条未触发"
- 每条显示：条件描述、当前值、阈值、证据链接

**区块 C — 六个核心数字**
主力合约价、现货价、基差、近月次月价差、SHFE 库存及日变化、汇率。
每个数字下方显示 `as_of` 与来源缩写；派生值（基差、价差）带展开按钮，显示输入与时点。

**首屏以下**（折叠或滚动区）：
1. 期限结构曲线 + 全合约表
2. 库存与仓单
3. 进出口（月度量、同比、分国别、近 13 月）
4. 数据缺口清单
5. 白名单指标一览

### 4.3 判断页

**查看态**：按九字段分区展示，阈值与证伪条件各一张表，顶部显示版本与状态。

**编辑态**：
- 分段保存，每段独立保存按钮，不强制一次填完
- 白名单、阈值关联指标、证伪绑定指标均为下拉选择，支持搜索
- 提交前弹出审稿清单结果，可选择"仍然提交"并记录
- 保存后显示与上一版的 diff

**版本历史**：版本列表 + 任意两版对比视图。

### 4.4 指标管理页

三个标签：指标登记表（列表 + 新增 + 编辑）、口径字典、人工录入（选择指标 → 填值 → 填 as_of → 填来源）。

### 4.5 日报归档页

日期列表 + 当日报告正文，提供 HTML / JSON / CSV 三个下载入口。

### 4.6 图表规范（参考 metalsmarket 的部分）

| 图表 | 参考对象 | 我们的改动 |
|---|---|---|
| 期限结构曲线 | 其"期货合约结构"折线 | 只连接有流动性的合约；清淡合约以空心点表示并标注；不使用首尾两点判定 Contango/Back，按活跃段判定 |
| 跨期价差卡 | 其"近月/次月""主力/最远月"两张卡 | 增加"相对持有成本占比"一行；保留"未计资金与仓储成本"的口径注释 |
| 全合约表 | 其合约明细表 | 增加"价格类型"列，明确该行用的是最新价还是结算价 |
| 库存日变化 | 其 SHFE 库存卡 | 同一页只显示一个时点的库存值，避免同页两个日期并存 |
| 进出口分国别 | 其 customs-detail 页的集中度与来源国条形 | 保留 TOP N + 集中度 + HHI；数量单位强制标注实物吨 |
| 近 13 月柱列 | 其月度进口量柱图 | 同比标注改为"同口径同比"，口径变更时断开柱列并注明 |

**通用图表规则**：
- 每张图右下角标注数据时点与来源
- 不使用双轴图（易误读）
- 颜色只用于区分序列，不用于表达多空

### 4.7 交互规范（低摩擦的具体落法）

| # | 要求 | 落法 |
|---|---|---|
| I1 | 打开即用 | 登录后直接进入锡的今天，不需要选品种或日期 |
| I2 | 不跳页 | 数字的来源、历史、输入时点在原地展开，不新开页面 |
| I3 | 分段保存 | 判断表单每段独立保存，草稿自动留存 |
| I4 | 不手打 | 所有指标引用为下拉选择 + 搜索 |
| I5 | 一键导出 | 日报与表格导出不需要配置参数 |
| I6 | 少确认 | 仅在删除判断版本、确认证伪处理时弹确认框，其余操作即时生效 + 可撤销提示 |

### 4.8 空态与异常态

| 状态 | 呈现 |
|---|---|
| 尚未录入判断 | 品种页显示引导卡："尚未登记锡的研究判断"，按钮直达判断表单；事实区正常显示 |
| 指标未取到数 | 该位置显示"暂无数据"与预期更新时间，不显示 0、不显示上一日数值 |
| 派生值被拦截 | 显示"口径不一致，暂不计算"，并列出冲突的两个输入及其时点 |
| 判断已过期 | 顶部黄色条："该判断写定于 X，已超过复核周期 N 天" |
| 证伪已触发 | 顶部警示条 + 待确认事项 |

## 5. 数据需求

一期指标清单见 `04_附录 §2`。清单中需明确标注：一期自动 / 一期人工 / 二期接入。

**取数时点**：每交易日 16:30 收盘后一次，次日 08:00 前一次（补齐夜间发布的海外与宏观数据）。

| 可用性 | 工作日 07:00–20:00 可用；取数失败不影响页面访问 |
| 留痕 | 判断变更、人工录入、证伪处理全部留痕，不可删除 |
| 兼容 | 桌面浏览器优先；移动端可读即可，不要求编辑 |
| 备份 | 每日数据库备份，保留 30 天 |

## 7. 验收标准

### 7.1 功能验收

- [ ] 现有锡研究逻辑 prompt 的全部内容可完整录入，无字段丢失
- [ ] 每条证伪条件均绑定了可自动取数的指标，或被明确标记为人工判定
- [ ] 阈值存在两条以上时，未填冲突优先级则无法提交
- [ ] 基差、跨期价差可展开查看输入指标与各自时点
- [ ] 人为制造一次时点错位（如用前一日现货价与当日期货价），系统拒绝出数并提示原因
- [ ] 人为使某指标停更，品种页出现数据缺口提示且不显示旧值
- [ ] 将判断的复核周期设为 1 天，次日全部页面出现"已过期"标记
- [ ] 构造一次"连续两期累库"，系统触发对应证伪条件并生成待确认事项
- [ ] 每日 JSON 快照字段完整，含 judgment / observations / derived / signals / gaps
- [ ] 日报可按历史日期回看

### 7.2 行为验收（上线后 4 周评估）

- [ ] 研究员每日手工取数时间下降（对比上线前基线，基线需在开发期内测量）
- [ ] 锡的判断在系统内至少有 2 个版本（说明她在用而不只是录了一次）
- [ ] 至少一次证伪或阈值触发是由系统先于人发现的
